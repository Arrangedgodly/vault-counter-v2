## Platform

web

## Users and purpose

Vault Counter was created for coworkers counting money in a store's back office. Users count denominations and transfer the breakdown to a company spreadsheet. The owner also wants to demonstrate the project as a resume example.

## Capabilities and constraints

Count sealed coin rolls and boxes, loose bills, and bundles. Stores may use different bill bundle sizes, so the owner requested configuration controls for each small bill denomination. The existing stack is static HTML, CSS, and JavaScript. The refreshed app stores counts and configuration in the current browser and exports CSV. Shared administration and authentication are outside the current implementation.

## Confirmed visual commitment

The owner selected a compact, polished cash counting workspace with the original green, blue, and red denomination groups.
